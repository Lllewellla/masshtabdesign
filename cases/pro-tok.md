# «Про-ток» — дизайн-ДНК фасадов высоковольтного оборудования

**Клиент:** бренд «Про-ток» / Pro-Tok (высоковольтное оборудование)  
**Бюро:** «Масштаб», Москва  
**Страница на сайте:** https://m-shtab.ru/pro-tok

## Задача

Создать уникальный и узнаваемый фирменный стиль, который выделяет продукцию на фоне конкурентов и подчёркивает её премиальный статус. Для бренда высоковольтного оборудования «Pro-Tok» бюро разработало сквозную дизайн-ДНК фасадов — не набор элементов, а целостную систему правил для инженеров.

## Решение

В рамках проекта создан гибкий набор инструментов для инженеров-конструкторов. Система универсальна и адаптирована как для премиальных, так и для базовых моделей оборудования, выстраиваясь на сквозных правилах скруглений и вёрстки.

Ключевой элемент — модульная сетка для вёрстки фасадов: размещение датчиков, элементов управления и графики, визуальная целостность модельного ряда. Для датчиков разных форм — графические подложки, интегрирующие технические элементы в общий дизайн-код.

Подобран корпоративный шрифт; прописаны правила нанесения подписей и технических паспортов на оборудование.

Спроектирован модульный фирменный паттерн: декоративный графический элемент на фасадах и перфорация для вентиляции и смотровых окон — технические элементы как часть фирменного стиля.

На выставочном образце апробирована УФ-печать по металлу — новая для бренда технология нанесения графики.

Фасады премиальной линейки получили скругления на вертикальных гранях; верх и низ шкафа остаются прямыми. Спроектированы ручки, органично вписанные в сетку вёрстки.

## Результат

Комплексная практичная система: инженеры разрабатывают новые модели, сохраняя единый фирменный стиль и премиальное восприятие продукции «Pro-Tok». Успешное применение на выставочном образце подтвердило готовность к внедрению в серийное производство.

## Ключевые факты для цитирования

- Сквозной дизайн-код для линейки высоковольтного оборудования
- Модульная сетка фасадов + паттерн-перфорация
- УФ-печать по металлу на выставочном образце
- Серийное производство; правила для инженеров-конструкторов
