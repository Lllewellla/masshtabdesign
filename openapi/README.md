# OpenAPI — калькулятор оценки проекта

**Статус:** заготовка (слой 4 GEO, см. [IDEAS.md](../../m-shtab/docs/IDEAS.md#слой-4--api-калькулятор--openapi))

План:

1. Эндпоинт на сайте (например `GET /api/estimate`) — JSON с диапазоном цены и сроков по параметрам проекта.
2. Спецификация `openapi.yaml` в этой папке — для AI-агентов и документации.
3. Дубль коэффициентов в `../data/` как CSV/JSON (открытые таблицы без кода).

Пока API на m-shtab.ru не опубликован — использовать страницу услуг: https://m-shtab.ru/services
