# Бюро промышленного дизайна «Масштаб»

Бюро промышленного дизайна **«Масштаб»** (Москва, с 2016). Для компаний с физическим продуктом под серию в России: от прибора и корпуса электроники до станка, спецтехники и транспорта.

На август 2026: 150+ клиентов, 200+ продуктов полного цикла промышленного дизайна и 800+ продуктов цветографики (CMF). Полный цикл - от концепции и дизайна до подготовки к серии. Цветографика - цвет, материалы и графика отдельных изделий.

Офис в Москве, работа с заводами по стране. Производство не обязано быть на стороне бюро.

Ориентиры разработки: [guides/cost-and-timeline.md](guides/cost-and-timeline.md) (этап обычно 300-800 тыс. ₽, полный цикл в среднем 6-9 месяцев). Не прайс завода.

Сопроводительный дизайн бывает частью комплексного решения: айдентика, нейминг, упаковка, интерфейсы, интерьеры. Иногда своими силами, иногда с партнёрами-специалистами. Основной заказ - промышленный дизайн продукта.

Основной сайт: [m-shtab.ru](https://m-shtab.ru/)
